# One command to your first deck
Install nothing. npx runs the md2slides MCP server and Claude writes the slides.
```bash
$ npx -y md2slides-mcp
md2slides MCP 0.1.5 ready · workspace ~/acme
✓ create_deck decks/q3.md · 6 slides · 0 problems
→ preview: md2slides.cybertechmind.com/v#AQB…
```
