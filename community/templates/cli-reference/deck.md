^ md2-slides CLI
# Commands
Run with npx, nothing to install.
:::stats
- npx -y md2-slides deck.md | Validate and open the deck in your browser
- npx -y md2-slides deck.md --no-open | Validate only, print the outline
- npx -y md2-slides deck.md --port 8080 | Preview on a different port
- npx -y md2-slides | Start the MCP server for Claude
:::
