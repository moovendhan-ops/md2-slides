# Changelog

## 0.2.0 — 2026-10-11

- Syntax highlighting for md2slides directives, blocks, kickers and column breaks in Markdown files.
- Inline color previews and a color picker for hex and RGB values in decks.
- Completions for block types and styles, layouts, transitions, animations and directives.
- 73 community templates, including 67 single-slide layouts for developer, AWS/cloud, client, planning and pitch decks.
- New blocks from the md2slides engine: math (KaTeX), CSV tables and charts, animated counters and text animations.
- More reliable webview: clearer load errors, tighter content-security policy and sturdier Wasm loading.
- Rebranded to md2slides.

## 0.1.0

- First release: open Markdown decks as slides beside the editor, or with "Open With… → md2slides Slides".
- Live two-way sync with the text editor; the preview follows the cursor and "jump to source" moves it.
- Components view: drag slides and components to reorder them, edit raw Markdown in place.
- Customize panel (theme, fonts, layout, motion) and full presenter mode.
- Suggests opening Markdown decks as slides when they are opened (`slidewise.suggestOnOpen`).
